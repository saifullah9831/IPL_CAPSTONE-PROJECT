# IPL Data Analysis Capstone Project

## Project Overview
This project focuses on analyzing IPL (Indian Premier League) match data using Python. The objective is to explore the dataset, identify patterns, and generate meaningful insights through data analysis and visualization.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Files
- `IPL_Capstone_project.ipynb` – Jupyter Notebook containing the data analysis.
- `IPL.csv` – Dataset used for the project.

## Project Workflow
1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Data Visualization
5. Insights and Observations

## How to Run
1. Download or clone this repository.
2. Install the required Python libraries.
3. Open the Jupyter Notebook.
4. Run the cells to explore the analysis.

## Dataset
The IPL dataset is included in this repository as `IPL.csv`.
